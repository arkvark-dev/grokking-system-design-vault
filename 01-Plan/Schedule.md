# Schedule

← [[00-Home|Home]] · [[Interview-Rubric]] · [[Glossary]]

This is a **weekday** plan (Mon–Fri). Use weekdays for new notes. Use weekends for a mock or a rest day.

Pick one track:

- **8-week default** — one design per weekday in the design weeks.
- **6-week fast** — skip optional wrap-up notes and do two light blocks on two days.

Set your start date here: `_YYYY-MM-DD_`

Set your target interview date here: `_YYYY-MM-DD_`

## How to use a study day
1. Open the note for the day.
2. Check the study todos as you go.
3. Write in the empty Notes headings. Use your own words.
4. Set frontmatter `status` to `in-progress` or `done`.
5. Tick the same item in [[PROGRESS]].

Do not paste Educative lesson text into this vault.

## 6-week fast track

Skip optional wrap-up notes. Combine some block days. Keep weekday-only study.

| Week | Focus |
| --- | --- |
| 1 | All of Foundations from [[Introduction]] plus [[Building-Blocks-Introduction]], [[DNS]], [[Load-Balancers]], [[Databases]] |
| 2 | Remaining building blocks through [[Concluding-Building-Blocks]] (two notes on some days) |
| 3 | [[YouTube]], [[Quora]], [[Google-Maps]], [[Yelp-Proximity]], [[Uber]] |
| 4 | [[Twitter]], [[Newsfeed]], [[Instagram]], [[TinyURL]], [[Web-Crawler]] |
| 5 | [[WhatsApp]], [[Typeahead]], [[Google-Docs]], [[Deployment]], [[Payment]] |
| 6 | [[LeetCode]], [[ChatGPT]], [[Data-Infrastructure]], [[LLM-Support-Bot]], [[AI-Code-Assistant]], then one mock + [[Lessons-from-System-Failures]] |

On the fast track, cap each design note at 60 minutes. Come back only to weak topics.

## Catch-up rules
- If you miss a day, do not double forever. Skip a later optional note instead.
- TinyURL and Typeahead are good short catch-up drills.
- If a design takes more than 90 minutes, stop. Write what is missing. Move on.
